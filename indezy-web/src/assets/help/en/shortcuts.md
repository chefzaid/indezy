Indezy works entirely from the keyboard. A few shortcuts save time every day: adding an opportunity, searching, changing a stage and sorting the offer feed.

## Show the shortcut help

Press `Alt + Shift + H`, or open your account menu (your name, at the top right) and choose **Keyboard shortcuts**.

## App shortcuts

They work on every page once you are signed in. On a Mac, `Alt` is the Option key.

| Keys | Action |
| --- | --- |
| `Alt + Shift + N` | Create an opportunity |
| `Alt + Shift + F` | Open the opportunities list and put the cursor in its search |
| `Alt + Shift + S` | **Search everything**: opportunities, clients, contacts and notes (and, if you are a network member, members, posts and your messages); with AI on, **Search by meaning (AI)** finds the opportunities and notes that answer a question even in other words, each with why |
| `Alt + Shift + M` | Choose the stage of the open opportunity, or of the focused Kanban card |
| `Alt + Shift + H` | Show keyboard shortcuts |

Shortcuts are paused while you type in a field, use a menu or a dialog.

> **Tip:** on the Kanban board, Tab to a card before pressing `Alt + Shift + M`, then choose the stage from the menu to confirm the move.

## In the global search

| Keys | Action |
| --- | --- |
| `↑` / `↓` | Move between results |
| `Enter` | Open the chosen result |

Type at least 2 characters to search. The magnifier in the top bar opens it too.

## In the offer feed

These keys work while an offer of the feed has the focus: Tab to the list first (see [Offers](/help/offers)).

| Keys | Action |
| --- | --- |
| `J` / `K` (or `↓` / `↑`) | Move to the next or previous offer |
| `O` | Open the offer on its site |
| `S` | Save or unsave the offer |
| `H` | Hide or show the offer |
| `A` | Add the offer to the pipeline |
| `D` | Show or fold its details |
| `N` | Write a note on the offer |
| `X` | Select or unselect the offer |

## In the network

| Keys | Action |
| --- | --- |
| `Enter` | In a conversation, send the message |
| `Shift + Enter` | In a conversation, start a new line |
| `↑` / `↓` then `Enter` or `Tab` | Pick a member or tag suggested after `@` or `#` in a post |
| `↑` on **Like** | Offer the other reactions |
| `Enter` in **Search the network** | Open all the results |

See [Network](/help/network).

## On the dashboard

In **Prospection activity** (see [Dashboard](/help/dashboard)):

| Keys | Action |
| --- | --- |
| `←` / `→` | Previous or next week |
| `↑` / `↓` | Previous or next day |
| `Home` / `End` | First or last day |
| `Enter` | Keep the day's card open |
| `Escape` | Close the day's card |
