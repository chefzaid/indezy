Indezy se pilote entièrement au clavier. Quelques raccourcis vous font gagner du temps au quotidien : création d'opportunité, recherche, changement d'étape et tri du fil d'offres.

## Afficher l'aide des raccourcis

Appuyez sur `Alt + Maj + H`, ou ouvrez le menu de votre compte (votre nom, en haut à droite) puis **Raccourcis clavier**.

## Raccourcis de l'application

Ils fonctionnent sur toutes les pages, une fois connecté. Sur Mac, `Alt` est la touche Option.

| Touches | Action |
| --- | --- |
| `Alt + Maj + N` | Créer une opportunité |
| `Alt + Maj + F` | Ouvrir la liste des opportunités et placer le curseur dans sa recherche |
| `Alt + Maj + S` | **Tout rechercher** : opportunités, clients, contacts et notes (et, si vous êtes membre du réseau, membres, publications et vos messages) ; avec l'IA, **Chercher par le sens (IA)** trouve les opportunités et notes qui répondent à une question même dite autrement, chacune avec pourquoi |
| `Alt + Maj + M` | Choisir l'étape de l'opportunité ouverte, ou de la carte Kanban sélectionnée |
| `Alt + Maj + H` | Afficher les raccourcis clavier |

Les raccourcis sont suspendus pendant la saisie dans un champ, dans un menu ou dans une fenêtre de dialogue.

> **Astuce :** sur le Kanban, atteignez une carte avec Tab avant d'appuyer sur `Alt + Maj + M`, puis choisissez l'étape dans le menu pour confirmer le déplacement.

## Dans la recherche globale

| Touches | Action |
| --- | --- |
| `↑` / `↓` | Passer d'un résultat à l'autre |
| `Entrée` | Ouvrir le résultat choisi |

Tapez au moins 2 caractères pour lancer la recherche. La loupe de la barre du haut l'ouvre aussi.

## Dans le fil d'offres

Ces touches agissent quand une offre du fil a le focus : tabulez d'abord jusqu'à la liste (voir [Offres](/help/offers)).

| Touches | Action |
| --- | --- |
| `J` / `K` (ou `↓` / `↑`) | Passer à l'offre suivante ou précédente |
| `O` | Ouvrir l'offre sur son site |
| `S` | Enregistrer l'offre ou la retirer |
| `H` | Masquer l'offre ou la réafficher |
| `A` | Ajouter l'offre au pipeline |
| `D` | Afficher ou replier ses détails |
| `N` | Écrire une note sur l'offre |
| `X` | Sélectionner ou désélectionner l'offre |

## Dans le réseau

| Touches | Action |
| --- | --- |
| `Entrée` | Dans une conversation, envoyer le message |
| `Maj + Entrée` | Dans une conversation, aller à la ligne |
| `↑` / `↓` puis `Entrée` ou `Tab` | Choisir un membre ou un tag proposé après `@` ou `#` dans une publication |
| `↑` sur **J'aime** | Proposer les autres réactions |
| `Entrée` dans **Rechercher dans le réseau** | Ouvrir tous les résultats |

Voir [Réseau](/help/network).

## Sur le tableau de bord

Dans **Activité de prospection** (voir [Tableau de bord](/help/dashboard)) :

| Touches | Action |
| --- | --- |
| `←` / `→` | Semaine précédente ou suivante |
| `↑` / `↓` | Jour précédent ou suivant |
| `Début` / `Fin` | Premier ou dernier jour |
| `Entrée` | Garder la fiche du jour ouverte |
| `Échap` | Fermer la fiche du jour |
